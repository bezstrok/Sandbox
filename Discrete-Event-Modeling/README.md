# Дискретно-событийное моделирование (Discrete Event Simulation, DES)

**Дискретно-событийное моделирование** — это метод моделирования систем, в которых состояние
изменяется только в конкретные моменты времени (события), а не непрерывно.

Основные принципы:

- **События** — моменты времени, когда происходят изменения
- **Процессы** — последовательности действий, генерирующие события
- **Ресурсы** — ограниченные объекты
- **Очереди** — ожидание доступа к ресурсам

## Virus In Office

Проект моделирует распространение вирусной инфекции (COVID-19) в офисе.

### Основные параметры влияния

- **Модель здоровья сотрудников**: Healthy → Incubating → Sick → Recovered
- **Комнаты с различной вентиляцией**: конференц-залы, кухня, open space
- **Средства защиты**: маски и вакцинация с разной эффективностью
- **Карантинные меры**: автоматическая изоляция при превышении порога заболевших
- **Тестирование**: периодическая проверка сотрудников с изоляцией положительных случаев

### Сценарии симуляции

1. **baseline** — базовый сценарий без защитных мер
2. **partial_protection** — 50% сотрудников в масках
3. **high_protection** — маски + вакцинация
4. **poor_ventilation** — плохая вентиляция помещений
5. **aggressive_testing** — частое тестирование каждые 48 часов
6. **mixed_conditions** — комбинация различных факторов
